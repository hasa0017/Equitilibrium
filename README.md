# Equity Research

A full-stack Spring Boot + React application for real-time equity research and analysis.

## Stack

**Backend:** Java 21, Spring Boot 3.3, PostgreSQL, Flyway, Caffeine Cache
**Frontend:** React 18, TypeScript, Vite, TanStack Query, Recharts, Tailwind CSS

## Local Development

### Prerequisites
- Java 21+
- Node.js 18+
- PostgreSQL 14+
- Maven 3.8+
